# 코스피 100 · 코스닥 50 실시간 트리맵 히트맵

코스피 시가총액 상위 100개 / 코스닥 상위 50개 종목(우선주·ETF 제외)을 KRX 업종별로
묶어 KOSPD.com 스타일의 트리맵 히트맵으로 보여주는 프로그램입니다.

- **코스피 100 / 코스닥 50 전환** — 상단 버튼, 마지막 선택 기억
- **타일 크기** = 시가총액 비례
- **타일 색상** = 등락률 (-3% 파랑 ~ +3% 빨강)
- **정규장 / 시간외(프리·애프터마켓) 전환** — 시간외 거래 중이면 자동으로 시간외 뷰 시작,
  등락률은 네이버와 동일하게 전일 종가 대비
- **핀치 줌** — 확대하면 작은 타일의 종목명도 표시 (더블탭 확대/원복, 휠 줌, 드래그 이동)
- **자동 갱신** — 기본 20~30초 (간격 선택, 일시정지 가능)
- 종목 클릭/탭 → 상세 정보(정규장·시간외 시세, 시가총액), 네이버 증권 링크

### 앱으로 설치 (PWA)

- **안드로이드 (Chrome/삼성인터넷)**: 위 주소 접속 → 메뉴(⋮) → **"앱 설치"** 또는
  **"홈 화면에 추가"** → 홈 화면의 트리맵 모자이크 아이콘으로 실행 (전체화면 앱)
- **아이폰 (Safari)**: 공유 버튼 → **"홈 화면에 추가"**
- 카카오톡 등 인앱 브라우저에서는 설치 메뉴가 없으므로, 링크를 Chrome/Safari로 열어서 설치하세요.

소스는 저장소의 `docs/` 폴더 (GitHub Pages로 호스팅). 데이터는 3단계로 받아옵니다:

| 배지 | 경로 | 지연 |
|---|---|---|
| `실시간` | CORS 프록시 경쟁(race) → 네이버 증권 API | 없음 |
| `준실시간` | GitHub Actions가 장중 60초마다 `data` 브랜치에 커밋 → raw로 읽기 | 약 1~2분 |
| `지연 N분` | 위 둘 다 실패 시 5분 주기 `docs/data.json` | 표시된 분만큼 |

- 분 단위 갱신: `.github/workflows/heatmap-minute-updater.yml` (KST 08:00~20:00)
- 5분 주기 백업: `.github/workflows/update-heatmap-data.yml`
- 항상 `실시간`을 원하면: `proxy/cloudflare-worker.js`를 Cloudflare Workers(무료)에
  배포하고 `docs/app.js`의 `MY_PROXY`에 주소를 넣으면 됩니다.

## 실행 방법 (PC 로컬 버전)

`run.bat` 을 더블클릭하면 패키지 설치 후 서버가 시작되고 브라우저가 자동으로 열립니다.

수동 실행:

```bash
pip install -r requirements.txt
python app.py
```

이후 브라우저에서 http://127.0.0.1:8050 접속.

## 데이터 출처

| 데이터 | 출처 | 갱신 주기 |
|---|---|---|
| 시세·시가총액·시간외(NXT) | 네이버 증권 모바일 API | 화면 갱신 시마다 |
| KRX 업종 분류 | 다음 금융 API | 하루 1회 (`sector_cache.json`에 캐시) |

## 파일 구성

- `app.py` — Flask 서버 (시세 수집 + API + 웹페이지 제공)
- `templates/index.html`, `static/style.css`, `static/app.js` — 히트맵 화면
- `run.bat` — 원클릭 실행 스크립트
- `sector_cache.json` — 업종 분류 캐시 (자동 생성)

## 참고 사항

- 장 마감 후에는 마지막 종가(시간외 뷰는 마지막 시간외 체결가) 기준으로 표시됩니다.
- 등락률은 당일(1일) 기준입니다. 주간/월간 등 기간별 보기는 미포함.
- 신규 상장 등으로 업종 분류가 아직 없는 종목은 `기타` 그룹으로 표시됩니다.
- 비공식 API를 사용하므로 네이버/다음 API 구조가 바뀌면 수정이 필요할 수 있습니다.
