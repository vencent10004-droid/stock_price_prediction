# KOSPI 100 실시간 트리맵 히트맵

코스피 시가총액 상위 100개 종목(우선주·ETF 제외)을 KRX 업종별로 묶어
KOSPD.com 스타일의 트리맵 히트맵으로 보여주는 프로그램입니다.

- **타일 크기** = 시가총액 비례
- **타일 색상** = 당일 등락률 (-3% 파랑 ~ +3% 빨강)
- **자동 갱신** = 기본 20초 (10/30/60초 선택, 일시정지 가능)
- 타일에 마우스를 올리면 현재가·등락률·시가총액 표시, 클릭하면 네이버 증권 페이지 열림

## 실행 방법

`run.bat` 을 더블클릭하면 패키지 설치 후 서버가 시작되고 브라우저가 자동으로 열립니다.

수동 실행:

```bash
pip install -r requirements.txt
python app.py
```

이후 브라우저에서 http://127.0.0.1:8050 접속.

## 데이터 출처

| 데이터 | 출처 | 갱신 주기 |
|---|---|---|
| 실시간 시세·시가총액 | 네이버 증권 모바일 API | 화면 갱신 시마다 |
| KRX 업종 분류 | 다음 금융 API | 하루 1회 (`sector_cache.json`에 캐시) |

## 파일 구성

- `app.py` — Flask 서버 (시세 수집 + API + 웹페이지 제공)
- `templates/index.html`, `static/style.css`, `static/app.js` — 히트맵 화면
- `run.bat` — 원클릭 실행 스크립트
- `sector_cache.json` — 업종 분류 캐시 (자동 생성)

## 참고 사항

- 장 마감 후에는 마지막 종가 기준으로 표시됩니다.
- 등락률은 **당일(1일)** 기준입니다. 원본 사이트의 일주일/한달 등 기간별 보기는
  종목별 과거 시세 조회가 필요해 포함하지 않았습니다.
- 신규 상장 등으로 업종 분류가 아직 없는 종목은 `기타` 그룹으로 표시됩니다.
- 비공식 API를 사용하므로 네이버/다음 API 구조가 바뀌면 수정이 필요할 수 있습니다.
